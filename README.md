# Tailwind CSS Dashboard

A simple and professional responsive dashboard created using
HTML, Tailwind CSS and JavaScript.

## Features

- Responsive dashboard layout
- Sidebar navigation
- Search bar
- Statistics cards
- Revenue line chart
- Sales bar chart
- Traffic source chart
- Recent orders table
- Mobile responsive design

## Technologies Used

- HTML5
- Tailwind CSS
- JavaScript
- Chart.js

## Performance Optimization

The dashboard uses a simple structure with:

- Semantic HTML
- Responsive Tailwind classes
- Minimal custom CSS
- Lightweight JavaScript
- Responsive charts
- No unnecessary libraries

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

For a better development experience, use the
Live Server extension in VS Code.
